## 2024-07-10 - Adding Loading/Disabled States and Keyboard Focus Cues
**Learning:** This app's interactive buttons often lack proper visual feedback during asynchronous operations (like PDF generation) and miss clear keyboard focus indicators. Simply replacing text strips away icons, causing layout jumps. A missing `disabled` state is also a critical UX and accessibility issue for preventing double-submissions and providing screen reader status cues.
**Action:** Always verify that interactive buttons include `focus-visible` ring utilities for keyboard users, distinct `disabled:` classes (e.g., `opacity-50 cursor-not-allowed`) to prevent multiple clicks, and use an animated loading spinner while maintaining the button's icon structure during async tasks to prevent layout shifts.
